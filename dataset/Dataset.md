## Dataset

This project uses the public RGB-D cattle body condition score dataset:

Winkler Z., Boucheron L.
"Labeled RGB and depth images for cattle body condition score prediction"
Dryad Digital Repository.
https://doi.org/10.5061/dryad.tqjq2bw4s

The dataset is not redistributed in this repository due to its large size.
Users should download the original dataset from Dryad and place the files according to the following structure:

dataset/
├── 2/
├── 3/
├── 4/
├── 5/
└── 6/

where each folder corresponds to the original BCS category.
